# Nexus

> **Интеллектуальная система подбора пользователей**

Nexus — клиент-серверное веб-приложение, предназначенное для персонализированного подбора пользователей на основе анализа их интересов, предпочтений и истории взаимодействия.

---

## 📌 О проекте

Проект разрабатывается в рамках лабораторных работ по дисциплине **«Объектно-ориентированное программирование»**.

Основная идея проекта — создание рекомендательной системы, которая помогает пользователям находить единомышленников и людей с похожими интересами.

---

## ✨ Возможности системы

В рамках проекта планируется реализовать:

- 🔑 **Аутентификация:** регистрация и авторизация пользователей
- 👤 **Профили:** создание, редактирование анонимных/открытых карточек и управление интересами
- 🎯 **Рекомендации:** просмотр персонализированных подборок пользователей
- 🤝 **Взаимодействия:** система оценок и создание взаимных совпадений (matches)
- 💬 **Коммуникация:** обмен сообщениями в чате и система уведомлений

---

## 🏗 Архитектура и репозитории

Проект разделен на три основных репозитория:

| Репозиторий | Зона ответственности | Стек технологий |
| :--- | :--- | :--- |
| **`nexus-frontend`** | Пользовательский интерфейс, отображение данных и клиентское взаимодействие | React, TypeScript |
| **`nexus-backend`** | REST API, бизнес-логика, авторизация, управление БД и модуль рекомендаций | Java 21, Spring Boot, Spring Data JPA, Spring Security |
| **`nexus-docs`** | Требования, архитектура, UML-диаграммы, roadmap и документация команды | Markdown, PlantUML / Mermaid |
