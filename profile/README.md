# Nexus

## Интеллектуальная система подбора пользователей


Nexus — клиент-серверное веб-приложение, предназначенное для персонализированного подбора пользователей на основе анализа интересов, предпочтений и истории взаимодействия.


## О проекте

Проект разрабатывается в рамках лабораторных работ по дисциплине "Объектно-ориентированное программирование".


Основная идея проекта — создание системы рекомендаций, которая помогает пользователям находить людей с похожими интересами.


## Возможности системы

Планируемый функционал:

- регистрация пользователей;
- создание профиля;
- добавление интересов;
- просмотр рекомендаций;
- система взаимодействий пользователей;
- создание совпадений;
- обмен сообщениями;
- уведомления.


## Архитектура проекта

Проект состоит из трех частей:


### Frontend

Репозиторий:

nexus-frontend


Отвечает за:

- пользовательский интерфейс;
- взаимодействие пользователя с системой;
- отображение рекомендаций.


### Backend

Репозиторий:

nexus-backend


Отвечает за:

- API;
- бизнес-логику;
- работу с базой данных;
- обработку рекомендаций.


### Документация

Репозиторий:

nexus-docs


Содержит:

- требования;
- архитектуру;
- диаграммы;
- roadmap;
- описание команды.
