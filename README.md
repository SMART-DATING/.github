# Nexus

> **Интеллектуальная система подбора пользователей**

Nexus — клиент-серверное веб-приложение, предназначенное для персонализированного подбора пользователей на основе анализа их интересов, предпочтений и истории взаимодействия.

---

## 📌 О проекте

Проект разрабатывается в рамках курса по дисциплине **«Объектно-ориентированное программирование»**.

Основная идея — создание рекомендательной системы, которая помогает пользователям находить единомышленников и людей с похожими интересами.

---

## ✨ Возможности системы

В рамках проекта планируется реализовать:

- 👤 **Профили:** регистрация, настройка аккаунта, управление интересами
- 🎯 **Рекомендации:** алгоритм подбора и просмотр подходящих анкет
- 🤝 **Взаимодействия:** система оценок, создание совпадений (matches)
- 💬 **Общение:** обмен сообщениями и система уведомлений

---

## 🏗 Архитектура проекта

Проект разделен на три основных репозитория:

| Репозиторий | Описание |
| :--- | :--- |
| **`nexus-frontend`** | Пользовательский интерфейс, отображение рекомендаций и клиентское взаимодействие |
| **`nexus-backend`** | REST API, бизнес-логика, работа с базой данных и алгоритмы подбора |
| **`nexus-docs`** | Требования, архитектура, UML-диаграммы, roadmap и документация команды |

---

## 🛠 Технологии

- **Frontend:** React, TypeScript
- **Backend:** ASP.NET Core, Entity Framework Core
- **Database:** PostgreSQL
- **Infrastructure:** Docker

---

## 🚧 Статус проекта

Проект находится в активной стадии разработки.
