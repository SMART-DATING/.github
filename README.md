# Nexus · Страница организации

Репозиторий содержит публичную страницу [SMART-DATING](https://github.com/SMART-DATING). GitHub показывает [profile/README.md](profile/README.md) на вкладке Overview организации.

Оформление использует логотип и сине-фиолетовую палитру Nexus. Баннер находится в [profile/assets/nexus-hero.svg](profile/assets/nexus-hero.svg), без внешнего генератора изображений.

Описание продукта и ссылки здесь должны оставаться краткими; подробные требования, схемы и инструкции находятся в [nexus-docs](https://github.com/SMART-DATING/nexus-docs).
